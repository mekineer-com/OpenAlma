memU Server address

Use the server address assigned by your private network. Saving does not configure the VPN or server listener.

For first installation, Iris receives this address automatically. If you change it later, also change it in Iris's Edit Connection and OpenAlma Mentra's Settings, where applicable.

Use a trusted private VPN or connection. Devices allowed to reach this endpoint can access the Soul's Iris data; trust the permitted devices and network access rules.

Phone steps

  1. Make the OpenAlma address above reachable through your trusted private connection.
  2. Connect the phone to that private VPN or connection.
  3. Install Mentra: OpenAlma Mentra (recommended for Iris automation) or Stock Mentra.
  4. Signing in to OpenAlma Mentra: choose OpenAlma if Android offers sign-in apps, or use email sign-in.
  5. For OpenAlma Mentra, enter the OpenAlma address in its Settings if the default does not connect.
  6. Install or update Iris using the installer below, then open it once.
  7. Allow Mentra microphone access. Android/Mentra asks for camera or photo access when needed.
  8. Choose a Soul on the phone, then tap Start to talk; listen for the beep.
