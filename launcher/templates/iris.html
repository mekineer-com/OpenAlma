Phone steps

  1. Make the WireGuard UDP endpoint reachable. Behind a home router, forward its UDP port to this host.

  3. Install Mentra.
  4. Install or update Iris above, then open it once.
  5. Allow Mentra microphone access. Android/Mentra asks for camera or photo access when needed.
  6. Test by tapping Start to talk with a Soul; listen for the beep.
